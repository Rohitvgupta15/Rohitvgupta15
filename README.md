## 🚀 Featured Projects

### 🧠 Oscillatory Neural Network on FPGA
**Digital ONN accelerator for pattern recognition**

- Designed and implemented an oscillatory neural network using Verilog/SystemVerilog.
- Implemented parallel oscillator neurons and programmable synaptic weights.
- Explored **4-bit, 8-bit and 16-bit phase resolutions**.
- Implemented the accelerator on a **Zynq-7020 FPGA**.
- Integrated the design with **PetaLinux** and a camera-based input pipeline.
- Investigated resource utilization, power, convergence time and classification accuracy.

🔗 [View Project](https://github.com/Rohitvgupta15/ONN-PetaLinux-FPGA)
